# ITAM platform: full-stack example

Teaching material for the **Frontend (ITAM)** course (`frontend-itam`) on
[courses.salut.uno](https://courses.salut.uno).

| Folder | What | Status |
| --- | --- | --- |
| [`backend/`](backend/) | **ITAM Board API**: a public, Trello-like API of events, ideas and questions with votes and comments. Students authenticate with a single `X-Course-Token` header. | Live at [`/example-backend/frontend-itam/docs`](https://courses.salut.uno/example-backend/frontend-itam/docs) |
| [`frontend/`](frontend/) | **ITAM Board**: the React app students build on that API in lessons 8–15 (Vite, TypeScript, React Router, react-hook-form, Zustand, FSD). It runs locally. | Ready: see [`frontend/README.md`](frontend/README.md) |

- [`docs/course-plan.md`](docs/course-plan.md) is the lesson plan the frontend follows.
- [`docs/example-backend-master-prompt.md`](docs/example-backend-master-prompt.md) is the
  contract the backend implements.
